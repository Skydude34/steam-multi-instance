# Steam Guard (.maFile)

Генерация кодов Steam Guard из `.maFile` — файла Steam Desktop Authenticator
(или другого инструмента, экспортирующего мобильный аутентификатор того же
формата). Код считается тем же алгоритмом, что использует мобильное
приложение Steam: TOTP (HMAC-SHA1, шаг 30 секунд) с заменой алфавита вывода
на `23456789BCDFGHJKMNPQRTVWXY`.

## ⚠️ Безопасность

`.maFile` содержит `shared_secret` и `identity_secret` — это эквивалент
пароля **и** доступа к 2FA аккаунта одновременно. Любой, у кого есть этот
файл, может:
- генерировать Steam Guard коды и логиниться за тебя;
- подтверждать трейды/обмены без твоего участия.

Поэтому:
- **никогда не клади `.maFile` в репозиторий** — `.gitignore` уже исключает
  `*.maFile` и папку `mafiles/`, но дополнительная проверка перед `git add`
  не помешает;
- храни файлы в `%LOCALAPPDATA%\SteamMultiInstance\mafiles\<instanceId>.maFile`
  (это путь по умолчанию в `MobileAuthStore`) — вне рабочей копии репозитория;
- если планируешь делиться этим проектом с кем-то — `.maFile` не передаётся
  вместе с кодом, у каждого свой.

## Использование

1. Экспортируй `.maFile` для аккаунта (например, через Steam Desktop
   Authenticator при привязке мобильного аутентификатора к новому устройству —
   это отвязывает Steam Guard от телефона и переносит его в файл).
2. Положи его в `%LOCALAPPDATA%\SteamMultiInstance\mafiles\<instanceId>.maFile`,
   где `<instanceId>` — тот же ID, что указываешь в GUI при запуске инстанса
   (например, `alice.maFile` для инстанса `alice`).
3. В GUI лончера выбери инстанс и нажми "Скопировать Steam Guard код" —
   текущий код попадёт в буфер обмена, вставь его в окно входа Steam.
